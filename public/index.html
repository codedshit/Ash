Background video

Autoplaying video behind the page. Needs the Uploads tab set up first if you're uploading a file directly (Cloudinary cloud name + unsigned upload preset).

If the upload fails: make sure the Cloudinary upload preset's Signing Mode is Unsigned and that its resource type allows video (Cloudinary → preset settings). Free unsigned presets cap uploads around 100MB — a large video may need compressing first. The button above shows the exact error Cloudinary returns if it fails.

Identity

Rings show as circular stat gauges in your Intel tab (max 2 looks best, but any number works).

Common ones: fab fa-discord, fab fa-github, fab fa-instagram, fab fa-tiktok, fab fa-x-twitter, fab fa-spotify, fas fa-link

Built-in tabs

Control which of the site's tabs are visible, and their label/icon. (The content inside each tab — bio, stats, player — isn't a page-builder yet; this controls visibility and naming. Want a whole new tab with your own content? See Custom Tabs & Widgets.)

Custom tabs & widgets

Add entirely new tabs next to Intel/Vibe/Music, each holding any number of free-form cards (a title + icon + text) — use these for hobbies, more about-me sections, anything.

Appearance

Drag any slider to resize that element. Each shows the normal (default) size, and Reset puts it back. These sizes apply the same on mobile and desktop.

0 = fully see-through cards, 1 = fully solid. Applies to every card on the site.

0 removes card edges entirely, 1 is the normal subtle border.

Upload your own fonts in the Fonts tab and they'll show up in these lists too.

Fonts

Upload a font file (.ttf, .otf, .woff, .woff2) and it's committed to your GitHub repo under public/fonts/, then shows up as an option anywhere you pick a font. Takes ~30–60s to go live after uploading (same as any other save, since it's a small deploy).

Uploads

One-time setup so you can drag in photos/audio/video from this panel instead of hosting them elsewhere first. Free, no code.

Create one free: Cloudinary dashboard → Settings → Upload → Upload presets → Add upload preset → set Signing Mode to Unsigned → Save → paste its name above.

Note: an unsigned preset is inherently public — anyone who inspects the page's network requests could see it and upload using it too. In Cloudinary's preset settings, set a max file size and allowed formats to keep that safe.

Discord

Requires your Discord account to be in the Lanyard server to work — that's what powers the live status.

Uses the Discord user ID above.

The target server must have Server Widget enabled: Server Settings → Widget → Enable Server Widget.
